# Responsive Design

This project builds a responsive news and portfolio website from semantic HTML
and plain CSS. It demonstrates flexible containers, responsive images,
breakpoints, a CSS-only hamburger menu, responsive typography, work cards,
footer adjustments, and an article-page hero correction.

The numbered files represent the progressive exercise checkpoints:
`01` through `10`. Each checkpoint has its own HTML and CSS pair so the
changes can be reviewed independently.

## Responsive features

- Flexible max-width containers
- Mobile, tablet, desktop, and large-screen breakpoints
- Responsive `srcset` image markup
- CSS-only navigation menu toggle
- Responsive typography based on root `rem` sizing
- Mobile work cards and footer layout
- Article page hero spacing correction

# Advanced CSS

This directory contains the progressive Advanced CSS exercises for the
Techium landing page.

## Files

- `images/` contains the project image assets.
- `styles/1-style.css` enables smooth scrolling.
- `styles/2-style.css` defines the initial color declarations.
- `styles/3-style.css` introduces reusable color custom properties.
- `styles/4-style.css` introduces reusable font-family custom properties.
